# PlaceLens · G1

Кликабельный макет, подготовлен 27.10.2026. Дизайн ожидает просмотра владельцем.
Наблюдения, выбор компоновки, проверки и основа G2 — в [основном плане](../../docs/interface-v2-plan.md#g1-исследование-и-кликабельный-макет-27102026).

## Локальный просмотр

Из корня репозитория, без установки зависимостей и сборки приложения:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory experiments/interface-v2
```

Открыть [макет](http://localhost:8765/). Сервер отдаёт только этот каталог и не проксирует запросы в API. В рамках G1 запущен отдельный loopback-сервер для просмотра; при завершении просмотра его можно остановить. Для запуска вручную в терминале — Ctrl+C.

`index.html`, `style.css`, `app.js` не входят в entry graph рабочего приложения. Никакие рабочие маршруты, Vite entry points или Compose-сервисы не добавлены. Для синтаксической проверки Node использовать только штатный контейнер:

```bash
docker compose exec --user node node node --check experiments/interface-v2/app.js
```

## Что можно попробовать

- Поиск → «Учебная, 12» → адрес → конкретное здание или отдельная адресная точка → профиль.
- Профиль → «Сравнить с другим адресом» → выбрать Б («Тихая, 8»). Замена сторон независима.
- «Поездки» внутри сравнения → «Заполнить демопример» → расчёт. У А успех, у Б уточнение; после явного выбора дорожной точки Б доступен отдельный пересчёт.
- «Пешком» → расчёт → «Выбрать улицы» → улица у старта и у цели → подтверждение. В сравнении затем «Пересчитать А/Б»; самостоятельный сценарий обновляет показательное состояние после выбора улиц.
- Самостоятельные поездки в шапке: отдельный старт и 1–3 цели, отдельный черновик от сравнения. Адресный поиск и выбор цели по схеме работают.
- Пустой поиск → «Выбрать точку на карте»: клик либо стрелки на прицеле и Enter / «Подтвердить точку». Доступны только остановки; адресный ID не создаётся.
- На телефоне — «Результаты / Карта». Источники, методы и ограничения раскрываются нажатием либо клавиатурой. «Почему так устроено» содержит небольшую схему альтернативы с двумя картами.

## Ограничения макета

Все адреса, ID, координаты, значения и SVG-геометрии вымышлены. Не выполнять по схеме навигацию на местности. Числа — готовые примеры, не результаты GIS или маршрутизатора. Слои иллюстрируют управление и не дают географического масштаба. Водный null имеет причину; значения за кругом не обрезаются до радиуса. Уличная линия отделена от исходных объектов; подходы не нарисованы.

Нет backend, внешних запросов, localStorage, публикации и переключателя «Текущий / Новый». Память вкладки сохраняет показательные черновики отдельно по сценарию, reload их очищает. Это не контракт нового межстраничного хранения G2. `#search`, `#compare`, `#trips` — только навигация макета, не форматы ссылок приложения. Не имитируются все API-ошибки, поздние ответы, восстановление личных ссылок и реальная MapLibre-камера.

Снимки браузера находятся в [screenshots/](screenshots/). Они показывают проверенные состояния макета, а не результаты сегодняшнего GIS-прогона.
