# PlaceLens Studio — самостоятельный дизайн-прототип

Статус: эксперимент для оценки дизайна, без интеграции и публикации. Создан 27.10.2026. Все объекты, геометрия, показатели, ID и результаты поездок синтетические.

Основной переносимый результат — `PlaceLens-prototype.html`: откройте его напрямую в обычном браузере. CSS и JavaScript включены внутрь; файл можно перенести отдельно. `index.html`, `style.css` и `app.js` — редактируемые исходники. Сборка, установка зависимостей и backend не нужны. `index.html?demo=compare` открывает заполненный пример; `?demo=partial` — частичный отказ. Начальная страница без параметров пустая. Если браузер не передаёт параметры локального файла, используйте кнопку «Открыть пример».

## Сценарии

- Выбрать конкретный объект А, прочитать профиль, добавить/заменить/удалить Б.
- Переключить общий радиус 300/500 м. Источники, методы, даты, покрытие и причины null доступны в строках и разделе данных.
- Добавить до трёх общих целей, переименовать или заменить их; один режим «Пешком / Авто», явный расчёт.
- Прочитать независимые результаты, показать маршрут, уточнить уличный старт или цель, повторить одну ячейку, очистить результаты без удаления ввода.
- Самостоятельные поездки со своим стартом и целями; остановки вокруг произвольной точки. Черновики отдельных сценариев сохраняются в памяти.
- Меню «···»: пустой экран, заполненное сравнение, загрузка, частичный отказ и отказ профиля Б.

## Дизайн и просмотренные референсы

Слева — короткий редактор выбора; справа — пространственный контекст и общая матрица результатов. Цвет, буква и форма различают А/Б; цели имеют отдельную нумерацию. На телефоне значения А/Б остаются рядом, карта открывается переключателем. Длинные данные читаются обычной прокруткой. Ограничения модели видны в контексте значений; полное происхождение раскрывается отдельно.

- [Google Maps](https://www.google.com/maps): в браузере просмотрен реальный интерфейс маршрутов, поля старта/цели и переключатель способов передвижения. Взята идея компактного ввода рядом с картой. Маршрутные расчёты Google не исследовались и не используются.
- [Denzify: открытый отчёт](https://denzify.com/sample): в браузере просмотрен реальный встроенный образец отчёта, карта, разделы фактов и методика, а не рекламные изображения. Взяты иерархия фактов и доступ к происхождению. Его оценки/рейтинг/вердикт не перенесены.
- Существующий `PlaceLens-prototype-g1.1-polish.html` изучен по исходному HTML/CSS/JS. Браузерный просмотр `file:` заблокирован политикой инструмента; обход блокировки не выполнялся.

## Упрощения

Поиск ограничен пятью синтетическими адресными объектами и тремя целями. Карта нарисована вручную и не предназначена для навигации; маршрут схематичен. Выбор улиц и проверка пути имитируются; валидаторы реального продукта не запускаются. Время синтетическое, пешком — только уличная часть с неизвестными подходами, авто — без пробок. Площади и проценты условные, Б по растительности — `null` из-за покрытия. Никаких запросов к аналитическому backend, аккаунтов, сохранения или персональных ссылок нет.

Проверки и снимки этого прототипа описаны в `QA.md`. Рабочее приложение и существующие изменения не затрагиваются.
