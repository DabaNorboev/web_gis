# Проверка самостоятельного прототипа

Статус: выполненная браузерная проверка 27.10.2026. Только новый эксперимент; рабочий frontend, backend, БД и геоданные не запускались и не менялись.

## Среда и результат

Chrome через браузерный инструмент, локальная статическая раздача Python на loopback. Проверены исходная версия и переносимый `PlaceLens-prototype.html` с включёнными CSS/JS. Физический телефон и screen reader не проверялись.

## Проверенные действия

1. Пустой экран → поиск А → ввод «Мира, 10» → ArrowDown → Enter → профиль. Затем поиск Б через Enter и заполненная пара.
2. Раскрытие растительности: `null` у Б, причина покрытия, метод, снимок и неизвестная дата наблюдения. Открытие источников, Tab и закрытие Escape.
3. Добавление общих целей, переименование, добавление третьей цели. Кнопки добавления четвёртой нет.
4. Явный автомобильный расчёт: наблюдалась загрузка четырёх ячеек, затем четыре результата. Показ одного выбранного маршрута на карте.
5. Смена режима очищает прежние результаты и скрывает линию; новый расчёт запускается явно. Без выбранных улиц пешие меры остаются неизвестными. Выбор старта оставляет запрос улицы цели; после её выбора появляется результат только своей поездки.
6. Частичный отказ: А → Работа и А → Спорт доступны; Б → Работа требует улицу; Б → Спорт возвращает ошибку. Повтор Б → Спорт восстановил только эту ячейку, остальные результаты сохранились.
7. Отказ профиля Б оставляет значение А видимым; повтор профиля Б доступен. У Б нет выдуманного нуля.
8. Самостоятельная поездка: произвольный старт на схеме без адресного ID → собственная цель → автомобильный расчёт. Результат сохраняется при переключении разделов.
9. Остановки: выбор точки без адреса → расчёт в 500 м → четыре демо-остановки; переключение 300 м требует нового явного расчёта. Пара А/Б и самостоятельный черновик сохраняются отдельно.
10. Слои мобильной карты переключаются; Escape закрывает меню. Все выбранные маркеры остаются в видимой области. Выбор улицы можно выполнить кнопкой или по схеме.

В финальном переносимом файле консоль Chrome не содержит JavaScript errors. Статическая проверка HTML не нашла повторяющихся статических ID и внешних runtime-ресурсов; CSS/JS находятся внутри файла. Проверка пробелов новых исходников и `git diff --check` успешны.

## Исправлено при просмотре

- Слишком длинная мобильная панель целей: заполненный редактор сворачивается, режим и число целей остаются в сводке, расчёт виден.
- Обрезанные маркеры на узкой карте: изменена мобильная компоновка схемы, все А/Б/цели доступны.
- Кнопка расчёта на коротком desktop: закреплена внутри прокручиваемого редактора, убрана нежелательная прокрутка корня.
- Избыточное повторение ошибки профиля: одна причина и один повтор на сторону, значения второй стороны сохранены.
- На карте рисуется только выбранный доступный маршрут, без линии недоступной стороны и без соединителей к объектам.
- Для нового пешего расчёта нужны явно выбранные уличные точки обоих концов; готовый пример содержит ранее выбранные демонстрационные улицы.
