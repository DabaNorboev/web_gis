# Проверка объединённого макета

Статус: выполненная браузерная проверка 27.10.2026. Это самостоятельный эксперимент с синтетическими значениями, без интеграции в приложение.

## Что проверено

Chrome, локальная раздача только нового каталога, четыре CSS viewport: **1440×900, 1280×560, 390×844, 320×740**. Все четыре размера просмотрены визуально. Горизонтального переполнения документа нет. На коротком desktop кнопка расчёта целиком доступна, нижняя граница — 488 px; таблица читается независимой прокруткой. На телефоне основные разделы доступны из нижней панели.

Переносимый `PlaceLens-visual.html` отдельно открыт и проверен. Golos Text загрузился из встроенного data URI; `document.fonts.check` подтверждает используемую гарнитуру. В документе нет внешних исполняемых script, таблиц стилей или шрифтов. Консоль финальной страницы не содержит JavaScript errors.

### Ориентиры и связь с картой

- Работа: изменение 20 → 25 минут стрелками клавиатуры обновило порог, обе шкалы и карточку карты. Б с 23 минутами перешёл от «+3 мин» к зелёному состоянию; сами 23 минуты не изменились. Нового расчёта не возникло.
- Остановка: изменение 250 → 300 м обновило шкалы и карточки А/Б на карте. Значение Б 290 м стало укладываться в личный ориентир. Исходные расстояния сохранились.
- Нажатие на спорт выделило строку и соответствующую карточку; остальные линии приглушились. «Одна цель» оставляет выбранную группу доступных связей. Недоступной поездке линия не рисуется.
- Добавлена третья цель. На 320 px все пять маркеров помещаются в видимую ширину, геометрических пересечений карточек нет. Карта остаётся схемой; позиции адаптируются для макета, а не вычисляются из настоящих геоданных.
- Для нерассчитанной третьей цели изменение ориентира 20 → 21 мин оставило обе ячейки неизвестными: чисел/нулей и маршрутных линий не появилось.
- Парк/дорога/вода показаны нейтральными шкалами. Часть за кругом — штриховка, а не оценка качества адреса.

### Ошибки, клавиатура и дополнительные сценарии

- Частичный отказ: две поездки доступны, одна требует улицу, одна возвращает ошибку. При повторе ошибочной ячейки наблюдался ровно один индикатор загрузки; после завершения доступны три поездки, остальные значения сохранены. Уточнение оставшейся улицы восстановило четвёртую.
- Отказ профиля Б: факт А 140 м остаётся видимым; Б получает неизвестность и один доступный повтор. На карте Б также перестаёт показывать недоступный факт остановки как известный. Повтор профиля работает.
- Диалог ориентиров на 320 px не имеет горизонтального переполнения. Слайдеры работают стрелками, Enter открывает действия, Escape закрывает диалог. Заголовок/закрытие сохраняются при прокрутке длинного окна.
- Переход к анализу остановок убирает прежние маршрутные линии и переключатель целей, показывает собственный контекст прямых расстояний. Выбор точки не создаёт адресный ID; расчёт запускается явно.
- Произвольный старт самостоятельной поездки имеет собственный маркер «С», без выдуманного адреса или данных профиля. Старые адреса А/Б сохраняются в отдельном сценарии.
- Пустое состояние, загрузка, частичный отказ и ошибка профиля доступны из меню состояний. При смене общего режима прежние результаты очищаются, новый расчёт явный.

## Исправления при просмотре

- Увеличены управляющие подписи и ключевые числа; шрифт с кириллицей включён в файл, исключена зависимость от случайного fallback.
- Убраны наложения карточек А/Б, работы и спорта на мобильной карте; для трёх целей применена отдельная схематичная компоновка.
- На мобильном заполненный редактор свёрнут в пару адресов, настройки доступны отдельно. Карта и сравнение не требуют прокрутки обратно к форме.
- Неизвестность не получает нулевую шкалу; при отказе профиля недоступные факты не остаются на карте как известные.
- Отдельные сценарии не показывают линии сравнения А/Б.

## Ограничения

Физический телефон и screen reader не проверялись. GIS, реальные маршрутизаторы, входы, подходы, актуальность данных и пробки не проверяются синтетическим макетом. Сравнение с личными порогами — новая гипотеза по прямому запросу пользователя, а не обещание существующего backend. Данные не сохраняются после закрытия страницы.

Изменён только новый каталог `experiments/placelens-visual/`. Прежний макет, приложение, зависимости проекта и staged/unstaged/untracked работа сохранены; ветка и HEAD не менялись. Рабочие данные, публикация, миграции, Git rollback и установка пакетов не выполнялись. Добавлен только локальный лицензированный шрифт как ресурс прототипа.

Проверка статического HTML и границ Git выполнена отдельно. `docs/` не редактировался; его checker, тесты рабочего приложения и GIS-наборы в этой итерации не запускались.
