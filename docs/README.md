- История upstream skeleton в корневом CHANGELOG не является журналом релизов PlaceLens.

## Как поддерживать документацию

1. Правило работы — AGENTS; команда запуска — README; критерий проверки — testing; контракт — документ функции; гипотеза — product-hypotheses; будущее — roadmap.
2. Обновлять основное место вместе с изменением поведения, в остальных местах давать ссылку. Не дублировать большие инструкции в AGENTS/PROJECT/README.
3. Отделять реализованное, предложенное и фактически проверенное. У исследования/протокола указывать дату, статус и ограничения.
4. Новые локальные ссылки делать относительными к документу для переносимости checkout. Секреты и личные точки не копировать в docs.
5. Порядок чтения контекста агентом — в [AGENTS](../AGENTS.md#начало-и-границы-задания). Этот индекс помогает выбрать документ; все перечисленные материалы не являются обязательным списком чтения.
