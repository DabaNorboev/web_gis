# Сообщения об отказах `/trips` — 21.10.2026

Уточнение следующего этапа: `SNAP_CHOICE_REQUIRED` показывается как отдельное
немодальное ожидание выбора, без оформления ошибки; варианты доступны в самой
карточке и на карте. См. [проверки выбора кандидатов](local-routing-candidate-choice-2026-10-21.md).

В карточке каждой нерассчитанной поездки показано постоянное немодальное
предупреждение: контрастный фон, рамка, значок, заголовок, объяснение и действие.
Карта и ввод не перекрываются. Успешные результаты остаются рядом; при правке
точек прежний результат сразу убирается, поздний ответ не возвращает его.

Ожидаемый состав до правок: отдельные сообщения о дороге/доступе/ограждении/
покрытии/техническом отказе; действия из карточки; скрытые технические подробности;
проверки частичного успеха, изменения точки, desktop/mobile и клавиатуры.
Исходное дерево сохранено в `/tmp/placelens-trip-notices-o1yb5igd/`.

## Контракт и формулировки

Сообщение выбирается по кодам backend в `checks`, не по тексту `reason`,
координатам, подписи или предположению о доступности места.

| Код или семейство | Основное сообщение и действие |
| --- | --- |
| `SNAP_NO_SAFE_CANDIDATE` | В пределах 35 м нет привязки, прошедшей проверки. Передвинуть исходную точку ближе к въезду/проезду |
| `SOURCE_*ACCESS_UNKNOWN`, `ENDPOINT_*ACCESS_REVIEW`, `SNAP_*ACCESS_UNKNOWN`, неопределённое направление/условие | Доступ не подтверждён. Выбрать дорожную точку до участка или другой подъезд |
| `SNAP_THROUGH_BARRIER`, `ROUTE_BARRIER_REVIEW` | В данных ограждение без подтверждённого прохода. Соединение через это место не подтверждено данными |
| `OUTSIDE_CONFIRMED_COVERAGE` / `OUTSIDE_PILOT` | Территория пока не охвачена |
| `ROUTER_UNAVAILABLE` / `UNAVAILABLE` | Временная техническая ошибка, повтор расчёта; при отсутствии snapshot отдельно сказано о недоступных данных |
| `SNAP_CHOICE_REQUIRED`, `SNAP_CANDIDATE_BUDGET` | Явный выбор кандидата или уточнение исходной точки |
| Прочие отказы | Различены отсутствие пути, уточнение привязки, недостаточная геометрия и незавершённая техническая проверка |

Коды и исходный `reason` доступны в закрытом по умолчанию блоке «Подробности
проверки». Основной текст не утверждает, что ограда закрыта или проезд запрещён,
когда данные подтверждают только неизвестность.

Resolver передаёт причины пустого результата кандидатов. SQL возвращает
метаданные отказа отдельной строкой только при пустом прежнем `selected`;
PHP распознаёт её до обработки списка и не считает кандидатом. Выбор/порядок
кандидатов, полоса неоднозначности, бюджет, радиус, source annotations и все
проверки доступа/препятствий остаются прежними. Координаты, OSM ID и геометрии
отклонённых объектов в новые диагностические поля не добавлены.

Постоянный `role=status`, `aria-live=polite`, `aria-atomic=true` объявляет результат
по номеру поездки и очистку старого результата. У карточек есть `aria-describedby`.
Фокус не захватывается автоматически; явное действие уточнения переводит его на
клавиатурно управляемую карту. Диалогов, блокировки страницы и смены `/trips` на
главную нет.

## Проверки

- Обычный PHP-suite: 25 тестов / 140 assertions, SQLite in-memory, fake HTTP.
- Только routing GIS: 29 тестов / 180 assertions, синтетические features,
  `web_gis_test`, принудительный READ ONLY. Проверены коды ограды/отсутствия
  кандидатов через настоящий provider/resolver/guard и сохранение прежних отказов.
- Frontend: 72 теста; выбор сообщений по кодам, SSR пяти причин рядом с успехом,
  отсутствие кодов в основном тексте, live status, очистка отказа и поздних ответов.
- TypeScript и production build из отдельной `/tmp`-копии — успешно. Прежние
  assets и manifest не перезаписывались. Осталось предупреждение large chunk.
- Реальный Chrome, отдельный синтетический API без БД/OSRM и request logging:
  отсутствие дороги, неизвестный доступ, ограда, технический отказ, граница пилота,
  частичный успех, повтор/удаление/изменение точек; ширины 1280/390/320, Enter,
  стрелки карты, перенос фокуса на canvas, подробности с клавиатуры. Горизонтального
  переполнения, модального перекрытия и ошибок консоли не обнаружено.
