# Концепт интерфейса задачи поиска

> Заменён [D13](../../../decisions.md#d13-анализ-места-перед-сравнением). План не активен; текст сохранён.

Статус: **предложение, визуальные ориентиры**. Девять изображений предоставлены владельцем и сохранены без изменений. Это примеры экранов и данных, а не снимки работающей версии, подтверждение GIS-результатов или поручение реализовать всё изображённое.

Основной документ — [контракт задачи поиска](../search-task-contract.md). При расхождении текста/чисел/состояний на изображении с согласованным контрактом действует контракт. Например, расчёт запускается только по кнопке; каждый важный пункт имеет свой режим; сохранение подтверждается успешной записью, а числовые результаты первой версии не сохраняются.

## Что задаёт контракт, а не изображения

- Не более 5 кандидатов, пара А/Б — временные роли постоянных кандидатов.
- Один явный запуск поездок и окружения; добавление адреса не запускает аналитику.
- Два варианта ссылки, последствия импорта, подтверждение удаления и ошибки хранения.
- Загрузка, частичные отказы, уточнение улиц, устаревшие значения и исчезновение объекта.
- Мобильные карточки, три положения шторки, короткий экран, клавиатура и фокус.

Отдельно ещё нужны макеты состояний и мобильного «Сравнения». Текущие изображения не подтверждают доступность или адаптивность. Копирование материалов в docs не меняет статус текущей реализации и старых UI-планов.
