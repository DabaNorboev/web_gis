Полный [снимок прежнего roadmap](roadmap-before-analysis-2026-11-03.md) сохраняет также начальные незакоммиченные правки; текущая очередь — [roadmap](../plans/roadmap.md).

Читать только по прямому указанию. Результаты относятся к исходной дате и не подтверждают сегодняшнее состояние. Текущие документы — через [индекс](../README.md).
