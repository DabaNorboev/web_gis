# Сравнение двух адресов

Главная `/` — единое пространство с одной картой; прямая `/compare` — отдельная страница с двумя картами на desktop и переключением А/Б на узком экране. Это разные представления общих профилей и поездок, не переключаемые версии главной.

На главной поиск А/Б открывается отдельным окном; один выбранный объект даёт профиль, два — парные строки. Общий радиус, независимые замена/удаление и автообновление профилей сохраняются. Выбранная свободная точка получает подпись без запроса остановок.

Компоненты и владельцы — [frontend-structure](../frontend-structure.md), API/состояния поездок — [trips](trips.md), взаимодействие карты — [home-workspace-map](home-workspace-map.md).

<a id="матрица-на-новой-главной--g42"></a>

## Матрица главной

Вкладки новой главной: «Обзор / Поездки / Окружение / Данные». Обзор — native table общих целей и окружения с колонками А/Б. Одиночный профиль доступен до расчёта поездок. А — фиолетовый круг, Б — синий квадрат; числа нейтральны. При [текущей компоновке карты](home-workspace-map.md) таблица прокручивается, в том числе на 1280×720. Длинные подписи, ошибки и причины переносятся без обрезки.

Ширины таблицы: desktop — 17% названиям при паре, 25% одному профилю; таблица <600 px — 34%. Минимум колонки — 12%/28%. Ручки separator меняют соседние колонки указателем и ←/→ (Shift ×5); Home/End — пределы; Escape/двойной щелчок/↺ — сброс. Смена числа адресов/порога ширины сбрасывает размеры; стороны, URL и API прежние.

Вкладки связаны с одной активной `tabpanel`: `aria-selected`, `aria-controls`, управляемый `tabindex`, стрелки по кругу и Home/End; Tab проходит объяснение чтения и desktop-раскрытие к панели. Неактивное содержимое исключено из Tab-порядка. Переключение раздела не рассчитывает поездки, не меняет URL и не создаёт владельцев состояния. Запуск общих поездок открывает обзор. Самостоятельная поездка доступна через «Рассчитать маршрут»; свободная точка показывает адресную подпись, без анализа остановок.

Строка поездки определяется стабильным ID цели и стороной; окружение — категорией и ключом метрики. Загрузка, необходимость расчёта, уточнение улицы, технический отказ и неизвестность с причиной показаны отдельно. Ошибка профиля Б не прячет А; замена адреса и одиночный повтор сохраняют независимые результаты. Старые значения после изменения геометрии или режима не показываются как текущие. Существующие отмена, epoch/sequence, URL/history и маршрутные ограничения остаются у прежних владельцев.

У каждой ячейки, включая отказ поездки, есть ⓘ с причиной, источником, повтором и уточнением улиц; возврат к исходной ячейке следует [правилам фокуса](home-workspace-map.md#мобильные-экраны-прокрутка-и-фокус--g44). Для окружения короткое и полное объяснения определяет `homeMetricPresentation.metricExplanation`; индивидуальные backend reason, качество, доступ и неполное покрытие сохраняются. Null не изображается нулём. В обычной ячейке — число либо краткий статус и название объекта. Причины неизвестности, ошибки, предупреждения о точности/покрытии и методические пояснения открываются в ⓘ; null остаётся неизвестным. Различия источников/дат/методик — в ⓘ заголовка строки. Подробности содержат источник, снимок, метод, отдельные даты наблюдения/публикации/расчёта и подтверждённый радиус/буфер. Дата наблюдения не подменяется публикацией.

Темы «Что важно мне» сохраняют прежние настройки браузера; «Все показатели» открывают остальные темы, растительные территории, доли и площади. Короткие проверяемые факты, список отдельных остановок со стабильными ID и повторный показ выбранного объекта доступны в раскрытиях после таблицы. Ближайшая геометрия показывается только по совпадению ID; иначе доступен слой с явной оговоркой. «Данные» содержат происхождение профилей и поездок. Длина пути, модельное время, исходные и дорожные/уличные точки, диагностика, кандидаты, ограничения и источники поездки сохранены в её подробностях и разделе данных.

На телефоне колонки остаются парными, подписи переносятся, основные кнопки имеют высоту не меньше 44 px. Длинные результаты прокручиваются. Отдельные страницы `/compare`, `/address/:id`, `/trips` сохраняют своё представление. Точки подключения — [frontend-structure](../frontend-structure.md#два-представления-интерфейса), проверки и ограничения стенда — [testing](../testing.md#frontend-и-browser).

## Общая карта главной

Состав показа, выбор цели/стороны, камера, возврат к строке и мобильная навигация — [единый контракт карты](home-workspace-map.md). Таблица посылает намерение выбора, но не создаёт вторую модель результатов или GIS-расчёт.

<a id="личные-ориентиры-на-новой-главной--g42a"></a>

## Личные ориентиры главной

Ориентиры времени изначально не заданы; они личные, отдельны по режимам и общие для А/Б. Кнопка настройки ближайшей остановки убрана. «✓ В ориентире / ↑ … сверх» — отношение известного модельного времени к условию, без рейтинга адресов и победителя; числа нейтральны. Неизвестное не получает оценки.

Рядом с целью в таблице — условие «До N мин», если задано, и компактный карандаш. Карандаш открывает ту же цель в боковом редакторе: возвращает свёрнутую панель, на телефоне переключает «Настройки», раскрывает сохранённую карточку, прокручивает к ней и фокусирует название. Модальное окно ориентиров не используется. Другие карточки, адрес, точка и значения сохраняются; переход не рассчитывает поездки, не меняет URL, историю или камеру.

В карточке — необязательное поле «До … мин». Принимается конечное положительное число без верхнего предела; пустое снимает условие, ошибка сохраняет последнюю корректную настройку и блокирует сохранение. Корректный ввод применяется сразу, включая поздний допустимый ответ. «Сохранить» возвращает краткую карточку. Владелец настроек прежний; запросы, исходные данные, геометрия и sequence не меняются. Краткие статусы/шкалы известного результата остаются в таблице, подробные ограничения — в ⓘ. Правила сравнения — [поездки](trips.md#личный-ориентир-модельного-времени).


Сравнивается `duration_s` принятого через `acceptedTrip` результата с минутами × 60 до форматирования. Равенство входит в ориентир; малое превышение обозначается «менее 1 мин сверх». Loading, ошибка, ожидание расчёта, уточнение и непринятый route оценки не получают. Pending/failed самостоятельной поездки не использует прошлый ответ. Оценка относится к модели, не к обычному городскому времени или доступу к входу.

Единственный владелец настроек существует в памяти открытого рабочего пространства вне вкладок результатов. Ключи времени: сценарий, стабильный ID цели и режим. UI настройки остановки выключен; совместимые внутренние типы не означают наличие такой кнопки. Переименование и замена точки той же цели сохраняют условие; удаление цели удаляет оба режима. Замена/удаление А/Б, радиус и вкладки сохраняют условия оставшихся целей. Пересоздание цели при URL restore сбрасывает её ориентиры даже при совпавшем локальном ID; Back/Forward не переносит настройку на чужой выбор. Reload сбрасывает все ориентиры. БД, browser storage и новые поля query/fragment не используются. Ориентиры не передаются ни одним вариантом ссылки; текущее действие главной описано в [поездках](trips.md#единое-пространство-на-главной). Форматы ссылок и прежние правила приватности не изменены. UI функции относится только к новой главной.

## Пользовательский сценарий

Этот раздел относится к прямой странице `/compare`, а не к компоновке главной.

1. Открыть `/compare` или ссылку с адресным выбором. А/Б могут быть пустыми; выбрать конкретный объект для нужной стороны.
2. Найти второй адрес и нажать на объект в списке или на карте вариантов; с клавиатуры — Enter на сфокусированном варианте. Выбор сразу заменяет нужную сторону. До клика/Enter текущая сторона и URL не меняются; наведение и фокус дают только подсветку. Два независимых autocomplete имеют уникальные input/listbox/status ID и работают с клавиатуры. Альтернатива — открыть `/compare` и выбрать оба адреса там.
3. Сопоставить парные строки одинаковых показателей: остановки, парки, растительные территории, вода, крупные дороги, железная дорога. Расстояния/доли и раскрываемые площади совпадают с обычными профилями; длины линий не выводятся. Две карты выбранных вариантов показывают адрес и радиус; общий флажок включает официальные остановки на обеих картах. Список остановок доступен по ссылкам «Открыть профиль А/Б»; карты внутри поиска показывают только варианты выбора адреса.
4. Заменить либо убрать любую сторону, поменять общий радиус, скопировать ссылку. URL восстанавливает пару/радиус после обновления страницы и в другом открытии. При запрете clipboard можно скопировать адрес страницы или открыть предложенную ссылку.

Радиус общий: только 300/500 м. Отсутствующее или иное значение в URL выбирает 500 м; интерфейс показывает фактически используемый радиус. `left`/`right` могут отсутствовать. Неизвестный/некорректный ID остаётся ошибкой своей стороны и не заменяется первым результатом поиска. Одинаковый объект с обеих сторон разрешён с явным сообщением. Ссылка хранит выбор, а не исторический снимок: при повторном открытии используются актуальные активные локальные импорты; исчезнувший объект может дать 404.

## Данные и ограничения

Нового аналитического endpoint, таблиц или источников нет. `useAddressComparison` запрашивает существующий `GET /api/v1/addresses/{id}/profile` для каждой стороны. Запросы независимы; ошибка или недоступный источник у одной стороны не скрывает другую. Изменение одного ID запрашивает только эту сторону. Изменение радиуса очищает обе стороны и запрашивает оба профиля заново. Старые запросы отменяются, поздние ответы игнорируются, таймаут 15 с. Несоответствие ID/радиуса в ответе считается ошибкой, а не показывается под выбранным адресом.

Даты, источники, снимки, методы, актуальность и доступность сравниваются по метаданным ответа. Их различия отмечены возле строки. Покрытие показано отдельно для А и Б в каждом разделе. Профили запрашиваются отдельно: публикация нового снимка между запросами возможна; различие ID снимков показывается явно. Каждый отдельный профиль сохраняет фиксацию снимков перед расчётом. Неизвестные даты не становятся известными от совпадения снимков. Периодов наблюдения/истории пока нет; сравниваются текущие локальные наборы с известными ограничениями.

Ноль, неизвестный/недоступный показатель и ошибка блока различаются; [структура качества и методики](address-profile.md#ответ-и-качество) одинаковы с профилем. Сравнение не складывает доли независимых категорий и не назначает победителя. Владельцы и компоненты представления — [frontend-structure](../frontend-structure.md).

В текущем интерфейсе адреса А/Б находятся в компактной шапке, парные значения — в боковой области, карты на desktop стоят рядом; на узком экране показывается выбранная сторона А/Б. Полный адрес не повторяется в каждой строке показателя. Смена выбора записывает `pushState`, обработчик `popstate` восстанавливает URL при назад/вперёд и загружает только изменившиеся стороны.

## Текущая панель слоёв

На `/compare` одна `MapLayersPanel` управляет двумя картами. Desktop-панель изначально открыта, на узком экране закрыта; сворачивание сохраняет флажки и камеры. Сведения выбранного слоя имеют отдельные А/Б и закрываются по Escape с возвратом фокуса. Устройство панели прямого профиля задаётся [address-profile](address-profile.md#карта-прямой-страницы-профиля), главной — [home-workspace-map](home-workspace-map.md). Изменение меню не создаёт аналитических запросов.
