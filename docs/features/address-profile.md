# Профиль адресного объекта

Главная показывает профиль одного выбранного объекта в общей таблице; её представление — [контракт сравнения](address-comparison.md#матрица-на-новой-главной--g42), карта — [контракт главной](home-workspace-map.md). Далее описаны общий API профиля и отдельная страница `/address/:id`.

`GET /api/v1/addresses/{id}/profile?radius_m=500` доступен гостю. Радиус — только 300 или 500 м, по умолчанию 500; другое значение даёт JSON/422. `id` — конкретный `osm:node:…`, `osm:way:…` или `osm:relation:…` из локального набора адресов. ID адресной группы `address:<hash>` не принимается. Пример страницы: `/address/osm%3Away%3A71888335?radius_m=500`.

Профиль не назначает главное здание в группе. Объект ищется по типу и исходному OSM ID в активном снимке: исчезнувший ID не заменяется другим объектом с такой же подписью. Некорректный/неизвестный ID — JSON/404, недоступный адресный набор — JSON/503. Наличие объекта в OSM не гарантирует полноты адреса или актуальности сведений. `ST_PointOnSurface` — точка внутри контура, не подтверждённый вход.

## Разрешение ID без аналитики

`GET /api/v1/addresses/{id}` возвращает `{address, capabilities: {resolver_version: 1, selected_profile_version: 1}}`. `address` совпадает с адресной частью полного профиля: точный ID, подпись, object/geometry/bounds, исходный снимок и даты. Полей результатов и calculated_at нет. Общий [AddressResolverService](../../app/Services/Addresses/AddressResolverService.php) используется обеими операциями; resolver читает только активный успешный адресный снимок и объект, не вызывает окружение или сборку слоёв.

404 имеет `code: ADDRESS_NOT_FOUND`: некорректный/исчезнувший ID не подменяется совпавшей подписью или прежними координатами. 503 имеет `ADDRESS_SOURCE_UNAVAILABLE`: источник недоступен, это не отсутствие объекта. Неожиданный отказ resolver также возвращает безопасный 503. Ограничение — 120 запросов/мин; успешные ответы и предметные ошибки имеют `Cache-Control: no-store`, `Referrer-Policy: no-referrer`.

## Только выбранные блоки: контракт v1

`GET /api/v1/addresses/{id}/profile?scope=selected&profile_version=1&blocks[]=parks&radius_m=300` рассчитывает только запрошенные блоки и их слои. Whitelist: transport, parks, vegetation, water, roads, railways. Нужен непустой уникальный список, версия 1 и прежний радиус 300/500; неизвестные значения/версия, дубликаты, blocks без scope дают 422. Запрос без scope по-прежнему возвращает полный профиль; автоматического fallback с selected на полный расчёт нет.

Ответ содержит `scope: selected`, `profile_version: 1`, `selected_blocks`, address, point, radius_m, calculated_at и **только** выбранные entries в blocks. Незапрошенные блоки отсутствуют. В map остаются общий круг/bounds, stops_in_radius только для transport, area_layers/linear_layers только для запрошенных категорий. Общий круг не означает расчёт всех аналитических блоков. Снимки выбираются один раз на запрос; запрос повторного блока получает новые данные независимо от прежнего ответа. Метрики сохраняют собственные calculated_at и происхождение: верхний calculated_at не подменяет их даты и не обещает атомарного снимка нескольких запросов.

Ошибка анализа блока: `status: ERROR`, `data: null`, безопасный message и `code: BLOCK_CALCULATION_FAILED`; его слой наследует эту ошибку без дополнительного вызова map service. Отказ только геометрии слоя: `LAYER_CALCULATION_FAILED`, готовые метрики сохраняются. Независимые выбранные блоки продолжают работу. Неожиданный общий отказ selected даёт безопасный HTTP/503 с `SERVICE_UNAVAILABLE`. В логах selected остаётся только тип технического исключения; сырые SQL и вход не передаются. Старый полный профиль сохраняет прежние поля и тексты ошибок, получая дополнительные машинные коды для ERROR-блоков/слоёв.

Новые клиенты — [searchProfiles](../../resources/js/api/searchProfiles.ts), отдельные типы [searchApi](../../resources/js/types/searchApi.ts); полный AddressProfile не ослабляется до optional-блоков. Resolver проверяет точную идентичность/геометрию и capability; selected проверяет версию, ID/точку, радиус, набор блоков, базовую структуру метрик и слоёв. Capability selected_profile_version=1 нужна до запроса. Это структурная проверка ответа, не повтор GIS на frontend. Новые операции пока не подключены к публичному UI.

Контрактные проверки — [SearchProfileApiTest](../../tests/Feature/SearchProfileApiTest.php), клиент и реестр — [search-api.test.mjs](../../tests/frontend/search-api.test.mjs); совместимость полного профиля — существующий AddressProfileTest через защиту web_gis_test. Команды и эффекты — [testing](../testing.md).

## Карта прямой страницы профиля

На desktop рабочая область занимает остаток окна под шапкой. Профиль слева прокручивается независимо; раскрытие поиска, источников и слоёв не сдвигает и не уменьшает карту. Обычное колесо над картой прокручивает профиль, Ctrl/⌘ + колесо меняет масштаб, перетаскивание сохраняется. На мобильных форма, показатели и карта идут последовательно с прежними якорями.

Управление «Слои» находится внутри карты рядом с темой и изначально свёрнуто. Сразу доступны «Остановки» и «Парки», раздел «Дополнительные» содержит растительные территории, воду, крупные дороги и железнодорожные линии. Меню ограничено высотой карты и имеет собственную прокрутку; кнопки масштаба и атрибуция остаются свободными. Источники, состояния и независимые флажки всех шести слоёв сохранены. Escape закрывает сведения с возвратом фокуса, следующий Escape — меню; клик вне меню также закрывает его. Раскрытие не меняет камеру/выделение/тему и не вызывает API анализа.

Маркер адреса подписан «Выбранный адрес». Синие остановки имеют тёмную заливку и белую обводку 2,5 px. Общие `MapLayersPanel.floating`, `CityMap.overlayControls`, слот `controls` и параметр `scrollTarget` доступны для повторного использования.

## Ответ и качество

Ответ содержит `address` (подпись, конкретный объект, геометрия, точка, границы и происхождение), `point`, `radius_m`, `calculated_at`, `map` и `blocks`. Геометрия — EPSG:4326, lon/lat. `map` включает круг/границы PostGIS, официальные остановки и отдельные блоки площадных/линейных слоёв. Состав FeatureCollection, ограничение области и состояния слоёв определяют [остановки](map-stops-layer.md), [площади](map-area-layers.md), [линии](map-linear-layers.md); здесь задаётся общий envelope профиля.

Идентификаторы всех активных снимков фиксируются одним запросом до расчёта блоков; публикация нового снимка между расчётами не смешивает данные. Каждый блок имеет `status: READY | ERROR`, `data`, `message`. `READY` означает успешный расчёт ответа, включая явно недоступные показатели. Ошибка одного блока изолирована транзакцией/savepoint: остальные рассчитываются, подробности SQL не попадают в ответ. Полный сбой БД может сделать недоступным весь профиль.

Каждый показатель содержит `key`, `value`, `unit`, `source`, `dataset_import_id`, `observed_at`, `source_updated_at`, `calculated_at`, `quality`; показатели окружения также содержат `method_version`. В `quality` независимы `method`, `availability`, `freshness`, `reason`. Неизвестная дата наблюдения остаётся null/UNKNOWN; дата версии источника её не заменяет. Без результата значение null и method=null. Ноль показывается только как результат обеспеченного данными расчёта.

| Блок | Показатели и ограничения |
|---|---|
| transport | Количество точек остановок в радиусе и ближайшая остановка/расстояние по прямой. Официальный набор, без подмешивания OSM. Ответ сохраняет существующий транспортный контракт, включая качество подсчёта маршрутов; в первом профиле показаны точки и расстояние. |
| parks | Доля/площадь объединённых контуров leisure=park и расстояние до ближайшей геометрии. Не обещает общественного доступа. |
| vegetation | Доля/площадь объединённых объектов с растительными тегами OSM и расстояние. Не измеренная растительность/NDVI. |
| water | Доля/площадь объединённых водных полигонов и расстояние. Наличие воды и доступ к берегу на текущую дату не подтверждены. |
| roads | Расстояние до ближайшей линии motorway/trunk/primary/secondary, длина линий внутри круга. Не оценка шума, загрязнения или доступности дороги. |
| railways | Расстояние до ближайшей линии rail/narrow_gauge, длина линий внутри круга. Движение поездов и эксплуатация не подтверждены. |

Площади/доли — [union пересечений в EPSG:32646](area-analysis.md). Признаки парков и растительных территорий независимы, их доли не складываются. Расстояния до исходных геометрий — geography, не до входов. Ближайший объект может находиться за выбранным радиусом, но его расстояние должно помещаться в подтверждённую область поиска.

Методика API-длины линий и её версия — [линейные слои](map-linear-layers.md#метрика-длины-в-api). Длины остаются в API, но не показываются как пользовательский критерий.

У каждого источника отдельно оценивается [покрытие](coverage.md). За территорией сервиса — OUTSIDE_SERVICE_AREA и null/UNAVAILABLE; при неполном радиусе площадь/доля/длина/число не подменяются нулями. Подтверждённое геометрическое покрытие не является гарантией полноты картографических объектов. Показатели застройки, аварийные дома, новые POI, воздух, спутники, аккаунты и внешние аналитические API не включены.

## Интерфейс

Поиск на главной открывает профиль сразу после клика по конкретному объекту в списке/на карте или Enter на сфокусированном варианте. Внутри профиля доступен такой же поиск с картой вариантов и подсветкой; до явного выбора показатели и основная карта относятся к прежнему адресу. Наведение и фокус сами по себе адрес не меняют. URL хранит OSM ID и радиус, прямое открытие и обновление работают без аккаунта. При смене радиуса старые результаты очищаются, запрос отменяется, поздние ответы игнорируются, таймаут 15 с. Есть загрузка, неизвестный объект, недоступный адресный набор, ошибка и повтор.

### Обзор и данные

Панель разделена на вкладки «Обзор» и «О данных». Стрелки переключают вкладки с переносом фокуса, Home/End выбирают первую/последнюю; Tab ведёт в содержимое. Переключение не вызывает расчёт и не добавляет запись истории. Прежний якорь `#profile-sources` открывает «О данных». На desktop карта постоянно видна, ссылка «Карта и слои» показана только на телефоне; есть обратный переход к показателям.

| Группа обзора | Первоначально | По запросу |
|---|---|---|
| Транспорт | Ближайшая остановка, расстояние и выбор на карте. | Остальные точки и число в круге. Одноимённые точки сгруппированы визуально: у каждой свои метры, кнопка и ID; направление движения не предполагается. |
| Парки и вода | Ближайшие контуры в выбранном круге, названия и ограничения доступа. | Известные расстояния за кругом. |
| Дороги и пути | Ближайшие линии в круге, без оценки шума или опасности. | Известные расстояния за кругом. |
| Дополнительные сведения | Явное предупреждение при недоступности/неизвестном покрытии растительных территорий. | Растительные территории и доли круга; они описывают контуры OSM, не качество места. |

Выбранные 300/500 м — правило начальной видимости. Сворачивается только доступный результат строго за радиусом при подтверждённом покрытии. На границе, при нуле, недостатке данных, ошибке или неизвестном/частичном покрытии основная строка остаётся видна. Сворачивание не меняет поиск ближайшего объекта; карта по-прежнему ограничена кругом и может не содержать дальний объект. Внутри полигона расстояние до его геометрии равно нулю; это не расстояние до входа.

Вкладка «О данных» содержит адресный источник, дату наблюдения, отдельно версию/публикацию, актуальность, доступность и покрытие результатов. Сведения объединяются только при совпадении источника, ID снимка, временных отметок, версии метода, всего качества (включая причины) и покрытия. Совпадающие даты и условия снимка вынесены в общий заголовок; разные причины качества остаются отдельными пояснениями каждого показателя в раскрытии. Ошибки показаны отдельно. Причины, методы, координаты, ID и технические сведения доступны в раскрытии; дата снимка не называется датой проверки объекта. Неизвестная дата остаётся неизвестной.

Распределение компонентов — [frontend-structure](../frontend-structure.md). Представление профиля на главной и `/compare` не определяется компоновкой этой прямой страницы.

При смене радиуса значения прежнего расчёта очищаются; известные адрес и точка остаются на месте до ответа. URL хранит конкретный объект и радиус; смена радиуса создаёт запись истории, назад/вперёд восстанавливают радиус без дополнительной записи. Прямое открытие и обновление работают без аккаунта. Ссылка открывает текущие данные, а не исторический снимок. Переход к сравнению передаёт тот же объект и радиус; сравнение сохраняет полный прежний набор показателей API.

Выбор остановки из списка включает её слой и выделяет точку; отключение снимает выделение. Источник, поведение переключателя и URL — [контракт остановок](map-stops-layer.md). Группировка одинаковых метаданных и раскрытие причин выше относятся к представлению профиля, не к изменению ответа API.
