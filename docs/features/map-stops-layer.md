# Переключаемый слой официальных остановок

Управление обновлено 23.10.2026: темы подложки, подпись выбранной остановки и свёрнутая легенда фактически показанных данных. Сведения по «О данных» и ручные переключатели сохранены. [Актуальные взаимодействия и проверки](../history/map-visual-interaction-2026-10-23.md). Ниже — методика и исторические проверки слоя 20.10.2026.

Этап завершён 20.10.2026. В профиле есть один переключатель, в сравнении — один общий для двух карт выбранных вариантов. По умолчанию слой выключен. Это точки **официального набора 24bpd**, а не OSM. Карты поиска адресных вариантов не получают этот слой.

## Данные и поведение

Слой использует только существующее `profile.map.stops_in_radius`: те же ID и координаты, которые возвращены транспортным блоком зафиксированного снимка. Ближайшая остановка вне радиуса отдельно не добавляется. При переключении новых запросов нет; меняется видимость MapLibre-слоёв обычных и выделенной точки. Другие слои и геометрии не меняются. Главная сохраняет прежний транспортный режим и видимость остановок.

Легенда показывает синие официальные точки и оранжевую выбранную. Источник, дата публикации и дата наблюдения берутся из `blocks.transport.data.metrics.stops_count`, независимо для каждой стороны. Неизвестная дата остаётся неизвестной, импорт/расчёт её не заменяет. Ссылка ведёт на паспорт официального набора. Публикация не подтверждает актуальность на сегодня.

В профиле выбор остановки в списке включает слой. Выключение снимает выделение. В сравнении выделения независимы, видимость общая. Смена радиуса/адреса очищает прежние точки до нового ответа; флажок сравнения сохраняется. Новый профиль после перехода по ссылке начинает с выключенного слоя. Загрузка, пустой результат, частичное покрытие, отсутствие источника и ошибка различаются; ноль не означает отсутствие остановок на местности.

Состояние слоёв приложение пока не хранит в URL. Ссылки профиля/сравнения по-прежнему содержат адреса и радиус, без нового параметра; прямое открытие и обновление выключают слой. Назад/вперёд внутри сравнения восстанавливает адреса/радиус, сохраняя общий флажок страницы.

Сравнение получило две карты выбранных вариантов на существующем API профиля. При готовом анализе камера профиля/сравнения охватывает радиус, а не приближается повторно к контуру адреса. Для главной прежний приоритет камеры сохранён. Высота desktop-карты профиля уменьшена, чтобы переключатель и источник помещались рядом с картой; мобильная высота сохранена. Новых расчётов, радиусов, показателей или аналитических слоёв не добавлено.

## Безопасность проверки и сборка

Браузер проверял отдельный временный PHP-стенд: проект и сборка read-only, отдельный временный storage, сессии/кэш `array`, отдельное имя cookie. Все его соединения PostgreSQL использовали `PGOPTIONS=-c default_transaction_read_only=on`; значение проверено перед/после. Записывающих тестов и операций с основной БД не было, отдельная тестовая БД не требовалась. SQL, использованный для проверки, только читает данные. Никаких миграций, импортов и публикации снимков.

До/после совпали полные контрольные суммы строк **11 таблиц**: `dataset_imports`, `dataset_coverages`, остановки/маршруты/связи, адреса, здания, дороги, железная дорога, зелень и вода. Состав и активность снимков сохранены.

Сборка выполнена в контейнере без сети с read-only проектом/зависимостями, выход — временный каталог. Затем проверенные файлы перенесены в локальный `public/build`: обновлён только сгенерированный `manifest.json`, добавлены пять assets, старые assets не удалялись. Старая версия манифеста сохранена в `/tmp/placelens-stops-layer-check/original-build-overwrites/`. Предупреждения о размере MapLibre-бандла и необязательном fontaine прежние; новые зависимости не ставились.

Исходные пользовательские правки не сбрасывались; изменения внесены поверх них. Исходные геоданные и прежние отчёты не менялись. Полные логи сверки, браузерный сценарий и скриншоты находятся в новом `data/reports/stop-layer-2026-10-20/` (игнорируется Git). Временный PHP-стенд после проверки остановлен; постоянный сервис не добавлен. `git diff --check` пройден.

Сверка файлов относительно начала задания не обнаружила удалений или неожиданных изменений кода/данных. Отдельно изменился хеш служебного `.idea/workspace.xml`; он не редактировался этим заданием, причина изменения не устанавливалась. Детали — `file-preservation.json` в локальном отчёте.
