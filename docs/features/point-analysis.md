# Выбранная точка на главной

Клик по фону карты или Enter на сфокусированной карте ставит фиолетовый маркер и показывает [адресную подпись по локальному снимку](point-address.md). Это приблизительное положение: подпись не присваивает точке адресный ID и не подтверждает вход или доступ. Неоднозначность, отсутствие данных, ошибка и повтор сохраняются в `PointAddressLabel`. Запоздалый ответ не заменяет подпись новой точки.

Для произвольной точки главная не запрашивает `GET /api/v1/transport/analysis`, не показывает остановки, круг радиуса или транспортные результаты. API и серверные операции остановок сохранены для независимого транспортного контракта и адресных профилей. Остановки профиля по-прежнему включаются явно в слоях карты. Вкладки «Остановки» в боковой панели нет.

Поиск адреса открывается отдельным окном кнопками добавления или замены А/Б в разделе «Сравнение». Выбор конкретного объекта открывает профиль на главной; второй объект включает сравнение А/Б. Произвольная точка и адреса сохраняются независимо. Клик точки сохраняет карту на мобильном экране, подпись располагается в карточке у маркера; сброс убирает маркер и подпись. Выбор старта, места или улицы направляется владельцу [поездок](trips.md), а не в обычный выбор точки.

Состав карточки, её положение, выбор А/Б или старта и возврат фокуса — [контракт карты](home-workspace-map.md#главная-панель-и-карта). Здесь определяется смысл свободной точки: она не получает адресный ID автоматически; сравнение выбирает объект, старт маршрута — исходные координаты.

## Ссылка и история

Формат `/?lon=92.87&lat=56.01&radius_m=300` совместим с прежними ссылками. Координаты EPSG:4326 сохраняются без округления; `radius_m` (300/500, по умолчанию 500) сохраняет общий радиус адресного окружения и не включает анализ точки. Back/Forward/reload восстанавливают точку и подпись без транспортного запроса. Некорректная ссылка показывает ошибку без подстановки нулевой точки. Подпись определяется заново по текущим данным; её ID в URL не записывается. Несвязанные query-параметры сохраняются, сброс сохраняет общий радиус.

Устройство главной и карты — [home-workspace-map](home-workspace-map.md). Проверки используют синтетические API и не подтверждают реальные геоданные или физический телефон.
