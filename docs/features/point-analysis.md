# Выбранная точка на главной

Главная `/` — единый [анализ места](place-analysis.md). Клик по карте или Enter в режиме выбора создаёт точку без адресного ID. Подтверждение запускает POST place-analysis, серверный круг 200–1000 м и независимые блоки.

[Адрес-ориентир](point-address.md#ориентир-точки-на-analysis) не меняет координаты. Только «Анализировать этот адрес» переводит выбор в адресный объект. Ошибка/отсутствие/поздний ответ ориентира не мешает анализу точки.

## Ссылка и история

Старый workspace и его компоненты удалены по решению владельца. Состояние нового экрана пока не сохраняется и не восстанавливается из URL; существующие browser records не меняются. UI и проверки — [frontend](../frontend-structure.md).
