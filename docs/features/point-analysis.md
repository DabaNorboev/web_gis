# Выбранная точка на главной

Главная `/` — единый [анализ места](place-analysis.md). Клик по карте или Enter в режиме выбора создаёт точку без адресного ID. Подтверждение запускает POST place-analysis, серверный круг 200–1000 м и независимые блоки.

Кнопка «Найти адрес поблизости» явно запускает запрос Geoapify. Координаты точки сохраняются до отдельного подтверждения адреса. Ошибка, пустой результат или поздний ответ не мешают анализу точки. Возврат локального ориентира в карточку запланирован на Г6. [Текущее поведение](point-address.md#внешний-ориентир-г5) · [план Г6](point-address.md#план-единая-карточка-точки-г6).
