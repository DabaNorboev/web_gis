# Крупные дороги и железнодорожные линии на карте

Действующий контракт слоя профиля. Источники и геометрия ниже — основное место правила; компоновка главной — [home-workspace-map](home-workspace-map.md), отдельного профиля — [address-profile](address-profile.md), `/compare` — [address-comparison](address-comparison.md). Исторические проверки — [сохранённые фрагменты](../history/ui-contract-notes-2026-11-01.md).

на картах профиля и выбранных вариантов сравнения добавлены два независимых слоя, выключенных по умолчанию. Переключатели сравнения общие для обеих карт. Площади и официальные остановки сохраняют отдельное управление и прежние данные. Карты поиска не получают аналитические слои; главная использует их при показе адресного профиля.

Крупные дороги обозначены оранжевой сплошной линией с белой обводкой, железнодорожные — фиолетовым пунктиром с белой обводкой. Легенда объясняет источник, ID снимка, дату версии и неизвестную дату наблюдения отдельно для каждого слоя/стороны. Цвета подложки не переключаются вместе с аналитическим слоем. Прямое открытие/refresh начинает с выключенных слоёв; замена вариантов, радиуса и история внутри страницы сохраняют выбор. Состав URL прежний: адреса и радиус.

## Источник и пределы результата

Используются локальные снимки дорог и железной дороги, зафиксированные профилем. Их ID/даты определяются ответом, не константами прежнего выпуска. Даты и ID берутся из метаданных API, не заданы константами в UI. Атрибуция © OpenStreetMap contributors, ODbL, со ссылкой на страницу copyright сохранена в легенде.

- Крупные дороги: `motorway`, `trunk`, `primary`, `secondary` из существующего `osm_roads`.
- Железная дорога: `rail`, `narrow_gauge` из существующего `osm_railways`; трамваи не добавляются.

Показываются картографические фрагменты, без вывода об эксплуатации, движении, шуме, воздухе или безопасности. Пересечение линий на плоской карте не подтверждает соединение. Разные проезжие части, пути и OSM ID не объединяются, совпадающие линии сохраняются. Число фрагментов и длины не выводятся как новые показатели. Прежние строки длин дорог/путей в сравнении убраны из интерфейса; существующие расчёты и значения API сохранены. Профиль и раньше показывал расстояния до линий без их длины.

Пустой доступный слой означает только отсутствие найденных линий в выбранном снимке и области. Это не доказывает отсутствие объектов на местности. Ошибка/недоступность, загрузка и частичное покрытие имеют отдельные сообщения. При частичном покрытии возвращаются только известные фрагменты. Никаких рейтингов или общего балла.

## API и ограничение области

Существующий `GET /api/v1/addresses/{id}/profile?radius_m=300|500` дополнен `map.linear_layers.{roads,railways}`. Новых эндпоинтов, источников, импортов, миграций, схемы и снимков нет. Показатели/старые map-поля не меняются. Каждый слой — `{status,data,message}`; `data` — FeatureCollection с `coverage`, `radius_m`, `source`, `dataset_import_id`, `observed_at`, `source_updated_at`, `quality`. В properties каждого элемента только исходный ID, имя и тип. Длины в новом map-контракте отсутствуют.

`OsmLinearMapService` получает те же заранее зафиксированные ID снимков и покрытие, что существующий блок профиля. Область — пересечение метрического круга анализа EPSG:32646 (`quad_segs=64`) с `data_geom` соответствующего снимка. Сначала применяется bbox-фильтр по существующему GiST, затем пересечение кандидатов с областью, `ST_CollectionExtract(...,2)`, исключение пустых геометрий и преобразование в EPSG:4326 lon/lat (GeoJSON, 9 знаков). Сохраняются LineString/MultiLineString и разрывы частей; нет union, слияния по имени/близости или построения графа. Полные исходные длинные линии и весь город браузеру не передаются. При UNKNOWN/OUTSIDE_SERVICE_AREA или отсутствующем источнике — пустой недоступный слой.

Два ограниченных набора передаются в обычном ответе профиля даже при выключенных слоях. Переключение меняет только MapLibre layout visibility и не запрашивает новые данные/не сбрасывает геометрию. Перемещение карты также не расширяет область: фрагменты остаются ограничены анализом выбранного адреса. Для новых GeoJSON-источников задано `tolerance: 0`, чтобы MapLibre не отбрасывал короткие фрагменты при упрощении. Другие источники/слои не менялись. Ошибка геометрии слоя изолируется savepoint: показатели, площади и второй линейный слой остаются доступны. Исходные теги/геометрии в БД не переписываются.

## Метрика длины в API

Длина дорог/путей — `ST_Length(ST_UnaryUnion(ST_Collect(ST_CollectionExtract(ST_Intersection(ST_Transform(geom,32646),circle),2))))`, круг — `ST_Buffer` в EPSG:32646, `quad_segs=64`. Совпадающие отрезки считаются один раз, параллельные проезжие части/пути остаются отдельными линиями. Это длина картографических линий, не число улиц, полос, маршрутов или длина пешего пути. Версия — `osm_linear_geography_length_utm46_v1`. Расчёт и поля длины API сохранены для совместимости; длины не показываются в профиле, сравнении или легенде новых слоёв. Окружность отображения карты использует прежний транспортный geography-buffer; расчёт площадей/длин использует документированный метрический круг.
