## Задание и исходное поведение

На настоящем localhost до изменения исходников открыт профиль Ленина, 102 (`osm:way:71888335`, радиус 500 м). При 1280×720 шапка занимала 75 px; раскрытая панель слоёв — 257,19 px, карта начиналась на y=373,19, имела высоту 440 px и выходила за экран. Сворачивание переносило карту на y=190,5. Высота документа была 1532 px. Исходный снимок и размеры: `data/reports/profile-map-2026-10-23/before.png`, `reproduction.json`.

Критерий результата: на desktop карта занимает остаток окна под шапкой и не зависит от раскрытия настроек. Профиль прокручивается отдельно; обычное колесо над картой прокручивает профиль, Ctrl/⌘ + колесо масштабирует, меню прокручивается самостоятельно. На мобильных сохранён последовательный документ с формой, показателями, картой и переходами к разделам.

## Реализация

- В `AddressProfilePage.vue` заголовок, форма и результаты собраны в одну независимую `.profile-panel`. Карта занимает оставшуюся рабочую область под шапкой, разделитель ширины и клавиатурное управление сохранены.
- Внутри карты рядом с темами размещено свёрнутое меню «Слои». Основные переключатели — «Остановки», «Парки»; «Дополнительные» раскрывает растительные территории, воду, крупные дороги и железнодорожные линии. Все шесть моделей видимости, источники, даты и состояния данных сохранены.
- Высота меню ограничена размером карты с запасом для масштаба, шкалы и атрибуции; оно имеет собственную прокрутку. Escape закрывает сведения с возвратом фокуса, затем меню. Нажатие вне меню закрывает его; «На карте» закрывает меню и выполняет прежнее явное действие категории.
- Обычное колесо направляется в левую панель только на desktop, без аналитических запросов и изменения камеры. Ctrl/⌘ остаётся MapLibre, перетаскивание сохранено. Над картой есть компактная подсказка. Меню, сведения выбранного объекта и легенда сохраняют собственную прокрутку.
- «Дом» заменён на «Выбранный адрес». Широкая подпись учитывается при размещении и не сдвигает исходную геометрию. Кнопки темы, номера списка/карты и выбранный адрес используют зелёный акцент приложения; А/Б сохраняют свои прежние цвета. Остановки имеют более тёмную синюю заливку и белую обводку 2,5 px на всех темах.
- Подготовлены переиспользуемые `MapLayersPanel.floating`, `CityMap.overlayControls`, слот `controls`, параметр `scrollTarget` и `mapSidebarScroll.ts`. `ComparePage.vue` и пользовательский сценарий сравнения не переделаны.

URL, pushState/popstate, радиусы, fetch/composable, расчёты, качество и GIS-данные не изменялись. Слои по-прежнему выключены при полном открытии профиля; изменение их видимости не вызывает API. Отсутствие результата и ноль остаются различимы.

- `docker compose exec -T node npm run build -- --outDir /tmp/placelens-profile-map-build --emptyOutDir` — production build успешен. Сохраняется прежнее предупреждение о размере MapLibre-бандла, новых зависимостей нет.

Полный финальный browser smoke (`smoke-final-green.log`) прошёл **36/36** на 320×740, 390×844, 1280×720, 1280×560. После последних поправок адаптивного меню целевой набор `--grep='profile map fills'` повторён на тех же четырёх viewport.
