# Школы и детские сады OSM

Вход — сохранённый PBF Geofabrik Сибирского федерального округа от 18.10.2026, OpenStreetMap, ODbL-1.0. `school` берётся из `amenity=school`, `kindergarten` из `amenity=kindergarten`. Название, полигон здания сам по себе и соседство объектов не определяют категорию. Расстояния прямые до исходной геометрии. Полнота, актуальность, доступ и закрепление по адресу школы не подтверждаются. [API](../features/place-analysis.md#5-блок-poi).

## Воспроизведение

Для каждой категории запустить `scripts/prepare-osm-education.py CATEGORY PBF BOUNDARY NEW_OUTPUT --expected-pbf-sha256 SHA` в том же офлайн-образе, что и [подготовка парков](osm-parks.md#подготовленный-файл-и-воспроизведение). Использовать сохранённую сервисную границу. Manifest фиксирует SHA, дату PBF и учёт геометрий. Запуск не перезаписывает существующий каталог.

В проверенном целевом окружении применить миграцию `2026_11_25_000001_create_osm_education_tables.php`, затем вызвать `php artisan osm:import-education CATEGORY FILE --boundary=BOUNDARY --expected-sha256=SHA`. У категорий разные снимки и транзакции. Обе категории API включаются настройкой `PLACE_ANALYSIS_EDUCATION_ENABLED`, по умолчанию выключенной. Отсутствие активного снимка категории отображается как недоступность.

## Рабочее подключение

25.11.2026 на локальном стенде активированы школьный снимок №17 (184 объекта) и снимок детских садов №18 (295 объектов). Источник OSM от 18.10.2026. Подготовленные JSON, manifest и учёт отношений сохранены в локальном каталоге `data/prepared/education/osm-education-2026-11-25.2RfWiF`. Каждый вход повторно импортировался в изолированной базе и дал `skipped`.

На публичной контрольной точке рабочий API отдал школы / сады: 0 / 1 на 200 м, 2 / 1 на 500 м и 4 / 4 на 1000 м. Ответы четырёх прежних категорий совпали с контрольными по ID, расстояниям и счётчикам. Пользовательская приёмка впереди.

Точечный дамп реестра данных, миграций и границ, контрольные ответы, предыдущая сборка и копия настроек сохранены в `data/backups/education-poi-activation.KL0gE7`. Чтобы скрыть новые категории, установить `PLACE_ANALYSIS_EDUCATION_ENABLED=false`. Снимки можно оставить в базе.
