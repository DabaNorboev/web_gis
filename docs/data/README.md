# Подготовка и импорт данных

Инструкции подготовки локальных наборов. Подготовлены шесть спутниковых выпусков. Подключённые даты указаны в [локальном runbook](../runbook-local.md#локальные-спутники-рабочая-активация). Для воздуха готов офлайн-снимок А11.2. Рабочее получение данных и API станций запланированы на А12. Зависимости локальных входов — в [плане очистки](../plans/code-cleanup-plan.md#данные-снимки-отчёты-и-эксперименты).

Runbooks меняют целевые данные только при соответствующем поручении и установленном окружении.
