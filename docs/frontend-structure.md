# Фронтенд

Vue/TypeScript расположен в `resources/js`, стили — `resources/css`, Blade — `resources/views`. Точка входа `app.js` монтирует `pages/HomePage.vue` в Blade-оболочку `welcome.blade.php`. Главная PlaceLens реализована; остальные страницы и маршрутизация ещё не подключены. Пустые каталоги сохраняются через `.gitkeep`.

| Каталог в `resources/js` | Назначение |
|---|---|
| `pages` / `layouts` | Страницы и общие каркасы |
| `components` / `components/ui` | Переиспользуемые компоненты / shadcn-vue |
| `composables` | Реактивная логика Vue |
| `api` | HTTP-запросы к Laravel |
| `types` / `utils` | Общие контракты / функции без состояния |

Компоненты — PascalCase и `<script setup lang="ts">`, composables — `use...`. Локальные типы держать рядом с кодом. GIS-расчёты остаются на backend/ETL; внешние GIS-сервисы через UI не вызываются.

Алиас `@` указывает на `resources/js` в Vite и TypeScript. Используется TypeScript 6 для совместимости с `vue-tsc`; проверка типов включена в CI.

Tailwind CSS 4 подключён через Vite. shadcn-vue: `components.json`, нейтральная тема `reka-nova`, CSS-переменные в `resources/css/app.css`, локальный Instrument Sans. `utils/cn.ts` объединяет CSS-классы. Класс `.dark` включает тёмную тему; переключателя пока нет.

```bash
docker compose exec node npm run ui:add -- button
docker compose exec node npm run typecheck
docker compose exec node npm run build
```

Первая команда — пример добавления исходников в `components/ui/button`; Button пока не установлен. Добавлять компоненты по мере необходимости, проверять изменения исходников, CSS и lock-файла. CLI — dev dependency, версии закреплены в `package-lock.json`. Сборка и проверка типов не заменяют визуальную проверку страниц.

При первоначальном аудите production-зависимости были без замечаний, dev CLI — с 15 замечаниями (6 high, 9 moderate), без совместимого исправления; принудительное обновление не применялось. Перед обновлением повторить аудит.

Документация: [shadcn-vue](https://www.shadcn-vue.com/docs/installation/vite), [совместимость TypeScript 7](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/).

Главная: `HomePage.vue` собирает бренд, визуальный `AddressSearch.vue` и `components/map/CityMap.vue`. Карта MapLibre центрирована на Красноярске; локальный `maps/basemap.json` основан на [OpenFreeMap Positron](https://openfreemap.org/quick_start/), без POI/аэропортовых значков, с сохранённой атрибуцией. Подложка, glyphs и sprites требуют интернета; это отображение карты, не источник аналитических расчётов. Worker собирается Vite локально. Есть resize/cleanup и сообщение с повтором при ошибке загрузки. Поиск принимает/очищает текст, при отправке сообщает о будущей функции; API поиска адресов не подключён. Адаптивные стили главной — в `app.css`.

Компоновка главной: общая компактная шапка (бренд и город), боковая панель с объяснением и поиском, карта справа. На мобильных панель расположена над картой, страница прокручивается. Панель может расширяться категориями при их реализации; шапка — навигацией по мере появления страниц. Сравнение, личный кабинет и вход пока не реализованы и не показаны пустыми пунктами.

Транспортный анализ: клик на карту или кнопка «Анализировать центр карты» → `useTransportAnalysis` → `api/transport.ts` → локальный Laravel API. `TransportResults.vue` выделяет ближайшую остановку/расстояние, показывает число точек в 500 м и статус недостаточности данных маршрутов. Числа маршрутов скрыты; причины и метаданные раскрываются в «Источник и качество данных». Предыдущий запрос отменяется; старые ответы игнорируются, таймаут — 15 с. Есть loading/error/retry/reset. Выбранная точка, радиус и все точки остановок в нём — GeoJSON-слои MapLibre; ближайшая выделена более крупным оранжевым кругом, остальные — синие; ближайшая за пределами радиуса тоже отображается. Геометрия радиуса поступает из PostGIS. После выбора вводный текст уступает место результатам, на мобильных панель остаётся над картой.
