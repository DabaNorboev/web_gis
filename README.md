# PlaceLens

PlaceLens помогает сравнивать выбранные места в Красноярске по локальным данным об окружении и готовиться к проверке условий на месте. Пользовательские обещания и реализованные сценарии описаны в [продуктовом контракте](docs/product.md).

## Как запустить

Нужны Docker и Compose v2. Для нового окружения, существующих данных и отдельных routing overrides используйте [локальный runbook](docs/runbook-local.md). Он разделяет первый запуск, разработку и подготовленные автомобильный/пеший runtime; существующие `.env`, ключи и volumes сохраняются.

Приложение открывается через [localhost](http://localhost). Команды установки и миграций выполняются только при подготовке соответствующего окружения.
