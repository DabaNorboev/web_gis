# PlaceLens

Веб-ГИС анализа и сравнения мест в Красноярске. Приоритет разработки — законченный анализ одного адреса или точки; затем сравнение совместимых результатов.

## Вход для владельца проекта

- [Продукт](docs/product.md): цель, работающие возможности и ограничения.
- [План](docs/plans/roadmap.md): следующий шаг и зависимости.
- [Документация](docs/README.md): контракты, устройство и проверки.

## Как запустить

Для подготовленного окружения достаточно `docker compose up -d`: Vite запускается автоматически. Все сервисы описаны в одном `docker-compose.yml`, OSRM/ORS включаются опциональными профилями. Нужны Docker и Compose v2. Подготовка нового окружения и работа с существующим описаны в [локальном runbook](docs/runbook-local.md). Приложение открывается через [localhost](http://localhost).
