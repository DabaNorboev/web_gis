# PlaceLens

Веб-ГИС анализа и сравнения мест в Красноярске. Приоритет разработки — законченный анализ одного адреса или точки; затем сравнение совместимых результатов.

Текущий экран поддерживает POI и спутниковые TCI/NDVI; локально подключён набор шести дат. Воздух ещё не реализован. Приёмка первого ядра и А13 остаётся открытой. Старые визуальные интерфейсы удалены; API и browser records сохранены — [границы frontend](docs/frontend-structure.md).

## Как запустить

Для подготовленного окружения — `docker compose up -d`. Единственный `docker-compose.yml` сохраняет выбранный режим assets: `dev` с Vite или `build` с готовым `public/build`; OSRM/ORS включаются опциональными профилями. Нужны Docker и Compose v2. Команды подготовки и [выбор dev/build](docs/runbook-local.md#выбор-frontend-assets) описаны в локальном runbook. Приложение открывается через [localhost](http://localhost).

Чистый checkout запускается без спутниковых данных и не содержит локальных аналитических наборов. [Подготовка данных](docs/data/README.md) и [явная локальная активация спутников](docs/runbook-local.md#локальные-спутники-рабочая-активация) выполняются отдельно. Локально активированный экземпляр и build-режим не означают публичный деплой.
